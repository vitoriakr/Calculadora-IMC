# 📊 Calculadora de IMC

Projeto desenvolvido com **HTML**, **CSS** e **JavaScript** para calcular o **IMC (Índice de Massa Corporal)** e informar a classificação da pessoa conforme a tabela de IMC para adultos.

---

## ✨ Funcionalidades

- Inserção de peso em quilogramas
- Inserção de altura em metros
- Cálculo automático do IMC
- Exibição do resultado numérico
- Classificação do IMC
- Alteração de cores conforme o resultado

---

## 🧮 Fórmula do IMC

```txt
IMC = peso ÷ altura²
```

### Exemplo

```txt
Peso: 70 kg
Altura: 1.75 m

IMC = 70 ÷ (1.75 × 1.75)
IMC = 22.86
```

---

## 📋 Classificação utilizada

| IMC | Classificação |
|------|----------------|
| Abaixo de 18.5 | Abaixo do peso |
| 18.5 até 24.9 | Peso normal |
| 25.0 até 29.9 | Sobrepeso |
| 30.0 ou mais | Obesidade |
